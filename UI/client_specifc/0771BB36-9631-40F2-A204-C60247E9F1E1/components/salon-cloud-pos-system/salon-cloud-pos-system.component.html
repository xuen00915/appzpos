How it Works

  1. 1Place Order

    With built-in CRM, customer can login as member and manage their booking through POS, Website or Self Kiosk

  2. 2Select Schedule

    Select available schedule for the selected service to block the schedule

  3. 3Make Payment

    Customer make payment through either online or offline payment options including Visa, Mastercard, Apple/Google Pay, E-wallet, Paynow etc

  4. 4Package Management

    Packages for multiple services can be created and managed using a POS system for multiple visits.

  5. 5Order Process System

    Inhouse gets orders immediately from different platforms once payment is completed and Queue number will be generated

  6. 6Queue Display Number

    Bump off orders at the touch of a button on your Order Process Screen and the Queue number will update in real time.

  7. 7Complete Order

    All order details can be reviewed in Order tab and the report is generated in Report tab
